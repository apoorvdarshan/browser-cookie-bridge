Policy

Privacy, in plain language.

Browser Cookie Bridge is local-first. Local browser and Codex transfers stay on your Mac; Browserless Cloud is a separate optional destination that uploads only after an explicit action.

Effective August 14, 2026 · Version 1.3

Summary

The short version: local transfers do not send browser data to the developer or a remote relay. If you explicitly select Browserless Cloud and click Upload, authenticated profile state is sent directly to Browserless under its policies.

Data handled by the app

When you run a transfer, Browser Cookie Bridge may process the following data locally:

  • Cookie values and supported attributes such as domain, path, expiry, security, SameSite, and partition information
  • History URLs, when you explicitly enable history transfer
  • Compatible Local Storage, IndexedDB, Session Storage, service-worker, and related origin-storage files when you explicitly enable Full site data for a Codex import
  • Source and destination browser choices
  • Automation and interface preferences, including login sync, daily time, menu-bar visibility, and update checks
  • Local technical status needed to complete a transfer, such as whether a selected endpoint connected or Codex is running

The app does not access browser passwords, bookmarks, autofill, payment information, iCloud Keychain, or unrelated files.

When update checks are enabled, the app requests public release metadata from GitHub. If you approve an update, it downloads the architecture-specific DMG and SHA-256 file from GitHub Releases, verifies the checksum locally, and replaces the installed app in place. No cookie or history data is included in those requests.

Browser-to-browser transfer

Selected data passes through a short-lived broker bound to IPv4 loopback. The broker holds transfer payloads in memory, requires a random local token and expected extension origin, and does not write cookie values or history URLs to logs.

ChatGPT Codex import

For a Codex destination, the app reads the selected local Chromium profile and works with Codex's local data while Codex is closed. It creates a backup and a separate working copy, validates cookie and history databases, and replaces the destination only after checks pass. If you explicitly enable Full site data, the source browser must also be closed; compatible origin-storage directories are backed up and replaced as complete units rather than merged while live.

Optional Browserless Cloud upload

When you select Browserless Cloud, connect an account, review the warning, and click Upload, the app uses the official Browserless CLI to send cookies, local storage, and IndexedDB from the selected closed browser profile to the region and profile name you chose. History and saved passwords are not included. This is a direct request to Browserless, not a developer-operated relay.

The Browserless API token is stored in macOS Keychain. A short-lived adapter reads it, removes it from the environment before temporary Chromium starts, and invokes the official CLI without exposing the token in the OS command line or app configuration. Browser Cookie Bridge disables Browserless CLI telemetry. Browserless uploads are manual-only and do not run from Daily sync or Sync at login.

Website data

This static website does not set advertising cookies, use behavioral analytics, or embed trackers. It links to GitHub, Ko-fi, X, Tally, and other external services only when you choose to follow those links.

Windows waitlist

The optional Windows waitlist is hosted by Tally. If you open and submit it, Tally receives the information you choose to provide: email address, Windows version, processor type, browsers used, desired transfer paths, consent, and any optional comments. That information is used only to measure Windows demand and contact consenting participants about Windows testing and release updates. Tally's privacy practices govern its copy of the submission.

The service that hosts this website may receive standard request information such as your IP address, browser user agent, requested page, and timestamp. That processing is controlled by the hosting provider's own policy.

Local storage and retention

Configuration, generated extensions, the pinned runtime, and Codex backups are stored under ~/Library/Application Support/BraveCodexCookieSync/. Configuration and generated token files use user-only filesystem permissions. A Browserless API token, if provided, is stored separately in macOS Keychain.

The official Browserless CLI records the upload-disclaimer acceptance timestamp in ~/.browserless/config.json. Browser Cookie Bridge does not place the API token in that file.

The newest 14 Codex pre-change backups are retained. You control the Mac account and can remove local app data by uninstalling the app and deleting its Application Support folder after confirming you no longer need the backups.

Sharing and sale

Browser Cookie Bridge does not sell personal information. It does not send cookie values, history URLs, generated tokens, or browser databases to the developer, advertisers, or data brokers.

Your selected destination browser receives the data you explicitly transfer. The destination browser and websites you visit remain governed by their own privacy practices.

If you select Browserless Cloud, Browserless receives the authenticated profile state you explicitly upload. Browserless's terms, privacy policy, account controls, retention, and infrastructure govern that copy.

Your choices

  • Cookies can be turned off, although they are enabled by default.
  • History transfer is optional and disabled by default.
  • Daily sync can remain off or run at a local time you choose.
  • Sync at login, Open at login, menu-bar visibility, and automatic update checks can each be disabled.
  • You decide which source and destination browsers participate.
  • Browserless Cloud is optional, destination-only, and manual-only; you can disconnect it and remove its Keychain token at any time.
  • You can stop using the app and remove its local files at any time.

Security

Cookies are credentials. Protect your macOS account, use only profiles you own and trust, and never share generated extension folders or backups. Imported Codex cookies can remain readable to software running as your macOS user until the relevant website refreshes them.

For the full threat model and private vulnerability reporting instructions, read the Security Policy.

Children

Browser Cookie Bridge is a developer utility and is not directed to children. The project does not knowingly collect personal information from children.

Changes to this policy

This policy may change when the app's behavior or distribution changes. Material updates will be committed to the public repository, and the effective date above will be revised.

Contact

For general privacy questions, open a GitHub issue without including private browser data. For a suspected vulnerability, use the private process in SECURITY.md and do not post it publicly.
